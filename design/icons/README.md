# Icons

Project SVG set: 20 px grid, 1.5 px stroke, square caps, `currentColor`. To draw: tick (supported), cross (contradicted), half-filled circle (unsupported), question mark (unverifiable), dash (not checkable), loop arrow (stuck), pause bars (paused), bracket mark `[ - ]` (logo), plus scan, document, citation, code, calculator, history, chat, settings-free (use Phosphor for generic UI icons).
